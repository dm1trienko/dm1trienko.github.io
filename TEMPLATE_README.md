# dmitrienok.ru — шаблон для GitHub Pages

Это простой статический сайт (HTML+CSS+JS) без сборки.

Фичи из коробки:
- 📚 база материалов с поиском/фильтрами
- 🗂️ “Каталог” (семестр → раздел → материалы)
- 🗓️ отдельный раздел “Расписания” (расписания/графики/календарь, свой каталог)
- 📄 просмотр PDF/Excel/CSV/Markdown прямо на сайте + embed Google Sheets/Forms
- 📰 новости/анонсы (Markdown посты)
- 🗳️ опросы (каталог по категориям + embed через iframe)
- 🤝 “Сообщество”: роли и верификация, команда, список спонсоров
- 🌗 тёмная/светлая тема (переключатель)

## Что где лежит

- `index.html` — главная (внутри — вкладки: Главная / Материалы / Расписания / Новости / Опросы / Команда / Обратная связь / Донат)
- `viewer.html` — просмотр PDF/Excel/CSV/Google Sheets внутри сайта (по `?id=...`)
- `post.html` — страница поста (по `?id=...`)

Контент:
- `content/site.json` — настройки (бренд, ссылки, донат, контакты)
- `content/resources.json` — база материалов (файлы + ссылки)
- `content/schedules.json` — расписания/календарь/дедлайны (отдельный каталог)
- `content/news.json` + `posts/*.md` — новости/анонсы
- `content/polls.json` — опросы (с категориями/тегами)
- `content/community.json` — роли, правила верификации, команда, контрибьюторы и спонсоры

Техническое:
- `.nojekyll` — выключает Jekyll, чтобы GitHub Pages просто раздавал файлы как есть
- `CNAME` — домен (если используешь свой)

## Быстрый старт

1) Создай репозиторий на GitHub и залей содержимое этой папки в корень репо.
2) Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
3) (Опционально) Settings → Pages → Custom domain → `dmitrienok.ru`.

## Как добавить материал

Открой `content/resources.json` и добавь новый объект.

Примеры — в посте `posts/howto.md` (открывается на сайте: “Подробный гайд”).

## Как добавить расписание/календарь

Открой `content/schedules.json` и добавь запись.

Рекомендуемые поля:
- `kind` — вид (например: “Расписание”, “Сессия”, “Дедлайны”, “Консультации”)
- `semester`, `subject` — для каталогизации
- `type` + `url` — что это за материал и где он лежит
- `embedUrl` — если хочешь встроить Google Sheet/Calendar

## Как добавить новость

1) В `content/news.json` добавь запись:

```json
[
  { "id": "welcome", "file": "posts/welcome.md" }
]
```

2) В `posts/welcome.md` укажи front matter:

```md
---
title: Запуск dmitrienok.ru
date: 2026-01-09
tags: [анонс]
excerpt: Короткое описание для списка новостей.
---

Текст поста...
```

Дата используется для сортировки, а на сайте отображается в формате `dd.mm.yyyy`.

## Как добавить опрос

Открой `content/polls.json`.

Поля для каталогизации:
- `category` (обязательно) + `tags`
- `semester`, `subject` (если опрос привязан к конкретному курсу)
- `status: "active" | "archived"` (старые — в архив)

## Как ограничить добавление материалов только “верифицированным”

У статического сайта нет сервера/логина, поэтому доступ ограничивается на уровне GitHub:

- Держи репозиторий **публичным** (чтобы студенты читали) или **приватным** (если нужно ограничить доступ).
- Раздавай права на запись/мердж только доверенным людям.
- Для остальных — режим “предложений”: они создают Issue или пишут в Telegram, а ты добавляешь/мерджишь.

Сами роли и список команды/спонсоров редактируются в `content/community.json`.
