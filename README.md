# dmitrienok.ru — учебный хаб

Статический сайт (HTML+CSS+JS) на **GitHub Pages**. Идея хаба — ясность и структура: превратить разрозненные материалы в **рабочую систему**, где правильный путь — самый простой.

**Сайт:** https://dmitrienok.ru

---

## Возможности

- Вкладки: **Главная / Материалы / Расписания / Калькулятор / Новости / Опросы / Команда / Справка / Обратная связь / Донат**
- «Проводник» (папки и подпапки) для **материалов / расписаний / опросов / калькуляторов / справки**
- Умный поиск по каталогу (без регистра, с устойчивостью к опечаткам)
- Просмотр документов прямо на сайте:
  - **PDF** (PDF.js + поиск по PDF)
  - **Excel (.xlsx)** и **CSV**
  - **Markdown** (посты/заметки)
  - **Google / Яндекс** документы, таблицы и формы (встраивание через iframe + умное распознавание ссылок)
- Командная палитра (поиск / навигация / быстрые действия)
- KaTeX для формул и Mermaid для схем
- OG‑предпросмотр + нативная «Поделиться» (где поддерживается браузером)
- Избранное и Недавние (localStorage)

## Структура репозитория

- `index.html` — основной интерфейс (внутри — все разделы во вкладках)
- `viewer.html` — просмотр отдельного материала по `?id=...`
- `post.html` — просмотр новости/поста по `?id=...`

Контент (каталоги):

- `content/site.json` — бренд, домен, контакты, ссылки, донат
- `content/resources.json` — материалы (таблицы/конспекты/билеты/ссылки)
- `content/schedules.json` — расписания/графики/календари/дедлайны
- `content/polls.json` — опросы (каталог + архив)
- `content/calculators/index.json` + `content/calculators/*.json` — каталог калькуляторов (каждый калькулятор отдельным файлом)
- `content/news.json` + `posts/*.md` — новости/анонсы
- `content/info.json` — справка (подборка полезных ссылок)
- `content/community.json` — команда, роли, верификация, спонсоры

Статика:

- `assets/` — стили, JS‑модули, иконки
- `files/` — место для файлов (можно хранить и в любых других папках — главное, чтобы путь был в каталоге)

## Развёртывание на GitHub Pages

1) Создай репозиторий и залей содержимое в корень репо.

2) В GitHub открой:

- **Settings → Pages**
- **Deploy from a branch**
- Branch: `main`
- Folder: `/ (root)`

3) Если нужен домен — отредактируй `CNAME` (в шаблоне уже лежит `dmitrienok.ru`).

---

## Как добавлять материалы

Есть два режима:

- **Верифицированные участники** — добавляют через Pull Request.
- **Все остальные** — предлагают через Issues/контакты (после проверки материал добавляется в каталог).

Подробно: `CONTRIBUTING.md`.

### Минимальный пример карточки материала

`content/resources.json`:

```json
{
  "id": "sem1-matan-teormin-2025",
  "title": "Матан • Теорминимум • 2025",
  "type": "pdf",
  "url": "1_семестр/Матан/teorminimum_matan.pdf",
  "semester": "1 семестр",
  "subject": "Матан",
  "folder": "Теорминимум",
  "tags": ["теормин", "2025"]
}
```

> Файлы можно хранить прямо в репозитории (PDF/XLSX/CSV) — сайт сможет открыть их во встроенном просмотрщике.

## Верификация и роли

У статического сайта нет «логина», поэтому доступ контролируется на стороне GitHub:

- права на запись/мердж — только доверенным
- для остальных — Issues/PR/обратная связь

Описания ролей и участников обновляются в `content/community.json`.

## Локальный запуск

Самый простой способ проверить сайт перед PR:

```bash
python -m http.server 8000
# открыть http://localhost:8000
```
